## 🚀 Projects

### [Marketplace UMKM](https://github.com/satriaif/marketplace-umkm)
> Full-stack e-commerce platform for local UMKM products with a personalized recommendation system

- Built with **Laravel**, **Tailwind CSS**, **Alpine.js**, and **MySQL**
- Implemented **User-Based Collaborative Filtering** recommendation using Cosine Similarity
- Integrated **Midtrans** payment gateway (sandbox) with multiple payment methods
- Multi-role system: Admin, Seller, and Buyer with role-based access control

### [Aplikasi Persediaan Gudang](https://github.com/satriaif/aplikasi-persediaan-gudang)
> Warehouse inventory management system for tracking material stock and generating reports

- Built with **Laravel**, **Tailwind CSS**, and **SQLite**
- Incoming & outgoing material recording with stock threshold monitoring
- Transaction report export in **PDF**, **Excel**, and **CSV** formats
- Multi-role authentication: Admin and Petugas
